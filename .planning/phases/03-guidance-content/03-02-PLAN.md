Important implementation notes:
- `@ValidateNested({ each: true })` combined with `@Type(() => GuidanceSectionDto)` is required to trigger nested object validation — `@Type` is from `class-transformer` and enables class-transformer to instantiate typed instances so class-validator can recurse into them
- `@ArrayMinSize(1)` ensures an empty sections array is rejected with 400
- `@IsInt()` on `order` validates the field is an integer — if a float or string is passed, it returns 400
- `UpdateGuidanceDto` uses `PartialType` so all fields become optional (supports partial PATCH payloads)
- Do NOT add `@IsOptional()` individually to UpdateGuidanceDto fields — PartialType handles this

Create `src/modules/guidance/guidance.service.ts` with three public methods.

```typescript
import { Injectable, NotFoundException } from '@nestjs/common';
import { PrismaService } from '../../providers/prisma.service';
import { CreateGuidanceDto } from './dto/create-guidance.dto';
import { UpdateGuidanceDto } from './dto/update-guidance.dto';

@Injectable()
export class GuidanceService {
  constructor(private readonly prisma: PrismaService) {}

  async findByProgramOid(programOid: string) {
    const sections = await this.prisma.guidanceSection.findMany({
      where: { programOid },
      orderBy: { order: 'asc' },
    });
    return sections.map((s) => this.mapSection(s));
  }

  async upsert(programOid: string, dto: CreateGuidanceDto) {
    // Verify the program exists first
    const program = await this.prisma.program.findUnique({
      where: { oid: programOid },
      select: { oid: true },
    });
    if (!program) throw new NotFoundException(`Program not found: ${programOid}`);

    // Atomically replace all sections for this program
    const created = await this.prisma.$transaction(async (tx) => {
      await tx.guidanceSection.deleteMany({ where: { programOid } });
      const rows = await tx.guidanceSection.createMany({
        data: dto.sections.map((s) => ({
          programOid,
          key: s.key,
          title: s.title,
          body: s.body,
          order: s.order,
        })),
      });
      return rows;
    });

    const sections = await this.prisma.guidanceSection.findMany({
      where: { programOid },
      orderBy: { order: 'asc' },
    });
    return sections.map((s) => this.mapSection(s));
  }

  async patch(programOid: string, dto: UpdateGuidanceDto) {
    // Verify the program exists first
    const program = await this.prisma.program.findUnique({
      where: { oid: programOid },
      select: { oid: true },
    });
    if (!program) throw new NotFoundException(`Program not found: ${programOid}`);

    if (dto.sections && dto.sections.length > 0) {
      // Upsert each provided section by key (update if exists, create if not)
      await this.prisma.$transaction(
        dto.sections.map((s) =>
          this.prisma.guidanceSection.upsert({
            where: { programOid_key: { programOid, key: s.key } },
            update: {
              title: s.title,
              body: s.body,
              order: s.order,
            },
            create: {
              programOid,
              key: s.key,
              title: s.title,
              body: s.body,
              order: s.order,
            },
          }),
        ),
      );
    }

    const sections = await this.prisma.guidanceSection.findMany({
      where: { programOid },
      orderBy: { order: 'asc' },
    });
    return sections.map((s) => this.mapSection(s));
  }

  private mapSection(s: {
    key: string;
    title: string;
    body: string;
    order: number;
  }) {
    return {
      key: s.key,
      title: s.title,
      body: s.body,
      order: s.order,
    };
  }
}
```

Implementation notes:
- `upsert()` uses interactive `$transaction(async tx => ...)` (callback form) so it can perform deleteMany + createMany in a single transaction — the callback form supports multiple dependent operations whereas the array form only supports a static array of promises
- `patch()` uses the array form of `$transaction([...])` with a map of `upsert` operations — this is a true PATCH: only provided sections are touched, existing sections with different keys are left intact
- `findByProgramOid()` does NOT throw NotFoundException when sections are empty — it returns an empty array (a program may exist with no guidance yet)
- `mapSection()` strips the DB internal fields (`id`, `programOid`, `createdAt`, `updatedAt`) from the API response — the API contract returns only `{key, title, body, order}`
- The Prisma compound unique key name for `@@unique([programOid, key])` is `programOid_key` (Prisma auto-generates this name from the field names)
